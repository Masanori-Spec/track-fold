# Third-party test components

The geometric mark is a text glyph; all demonstration role/timing data is original
and synthetic. No licensed script or production photograph is included.

Development and verification tools only:

- Chromium: browser supplied by Playwright or the verification environment;
  not redistributed in the app or source ZIP
- LibreOffice: native CSV spreadsheet test consumer, not redistributed
- Poppler: CI PDF rendering/review tool, not redistributed
- Noto CJK fonts: CI rendering support, not redistributed

These notices identify test tools and do not select a license for TrackFold.
