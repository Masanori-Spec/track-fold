A BOUNDED, AUDITABLE MODEL

A candidate you can inspect

  1. Keep each role on one track

    Appearances may touch but never overlap. A same-role return needs zero changeover seconds in this version.

  2. Check the actual sequence

    Only neighboring appearances create handoffs. An intermediate role can change feasibility; a pairwise conflict graph would miss that.

  3. Finish the exact search

    All feasible subsets feed an exact partition search. Cancelled or budget-limited searches never claim a minimum.
